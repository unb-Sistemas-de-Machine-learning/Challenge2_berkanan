# ADR-007 — Integração e entrega contínuas

**Estado:** APROVADO

## Contexto

O projeto precisa garantir que alterações no código não comprometam a integração dos componentes e que a branch principal receba somente mudanças verificadas.

## Decisão

Adotar GitHub Actions para execução automatizada de verificações de integração contínua.

O pipeline deverá executar as verificações definidas para o projeto, incluindo:

- Verificação de sintaxe;
- Instalação e validação de dependências;
- Testes automatizados;
- Build e verificações dos containers;
- Smoke tests, quando aplicáveis.

## Proteção da branch principal

A branch `main` deverá permanecer protegida.

As regras aprovadas são:

- Pull requests devem passar pelas verificações de CI;
- É necessária pelo menos **uma aprovação** antes do merge;
- O merge deverá ocorrer exclusivamente por **merge commit**;
- Não serão permitidos merges que contornem as verificações e aprovações exigidas.

A proteção da branch principal e as regras de merge foram incorporadas ao fluxo do repositório.

## Consequências

- A integração ocorre por pull requests.
- A branch principal mantém um histórico explícito de merges.
- A aprovação e o CI funcionam como barreiras antes da integração.
- Não é necessário adicionar ferramentas externas de CI/CD além da solução aprovada.
