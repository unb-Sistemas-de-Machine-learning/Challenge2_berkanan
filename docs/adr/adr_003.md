# ADR-003 — Backend centralizado

**Estado:** APROVADO

## Contexto

O sistema precisa executar processamento de imagens, consultas às bases de dados, recuperação de documentos e orquestração dos agentes.

Executar essas operações no dispositivo móvel aumentaria a complexidade e os requisitos computacionais do cliente.

## Decisão

Adotar Python com FastAPI como backend central.

O backend será responsável por:

- Receber solicitações do frontend;
- Validar os dados de entrada;
- Orquestrar o processamento;
- Executar os agentes;
- Consultar PostgreSQL e ChromaDB;
- Retornar respostas estruturadas ao frontend.

O cliente móvel, executado no navegador, será responsável principalmente pela captura e compressão das imagens e pela apresentação dos resultados.

## Consequências

- O processamento pesado será executado no servidor.
- A comunicação entre frontend e backend ocorrerá por meio de uma API HTTP.
- A infraestrutura será mantida enxuta, conforme as decisões aprovadas para o projeto.
